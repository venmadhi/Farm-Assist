# FarmAssist Dataset Sources & Licensing Information

This document details the public plant disease datasets ingested by the FarmAssist ConvGeM-NeXt training pipeline.

---

## 1. Dataset 1 — PlantVillage

* **Official Source:** [Kaggle PlantVillage Dataset](https://www.kaggle.com/datasets/abdallahalidev/plantvillage-dataset)
* **Original Paper:** Hughes, D., & Salathé, M. (2015). *"An open access repository of plant image data for AI-based plant disease detection."* arXiv preprint arXiv:1511.08060.
* **Approximate Image Count:** ~54,304 images across 38 laboratory leaf classes.
* **License:** Creative Commons Attribution 4.0 International (CC BY 4.0).
* **Download Method:** Automated download using Kaggle API (`abdallahalidev/plantvillage-dataset`).

---

## 2. Dataset 2 — PlantDoc

* **Official Source:** [GitHub PlantDoc Repository](https://github.com/pratikkayal/PlantDoc-Dataset)
* **Original Paper:** Singh, D., et al. (2019). *"PlantDoc: A Dataset for Visual Plant Disease Detection."* CoDS-COMAD.
* **Approximate Image Count:** ~2,569 real-world field photographs across 27 classes.
* **License:** MIT License / Open Academic Research.
* **Download Method:** Automated git clone from official GitHub repository.

---

## 3. Dataset 3 — Coconut Tree Disease Dataset

* **Official Source:** [Mendeley Data — Coconut Tree Disease Dataset](https://data.mendeley.com/datasets/gh56wbsnj5/1)
* **Authors:** Mendeley Data Research Repository.
* **Approximate Image Count:** ~5,798 images covering Coconut Bud Rot, Leaf Rot, Stem Bleeding, Gray Leaf Spot, and healthy fronds.
* **License:** CC BY 4.0.
* **Download Method:** Automatic direct download or manual placement in `data/raw/coconut/`.

---

## 4. Dataset 4 — Pepper Bell Leaf Disease Dataset

* **Official Source:** [Mendeley Data — Pepper Bell Leaf Disease Dataset](https://data.mendeley.com/datasets/w9drvtxg9g/1)
* **Authors:** Mendeley Data Research Repository.
* **Approximate Image Count:** ~9,283 images of pepper bell foliar diseases (Bacterial Spot, Cercospora, Phytophthora, healthy).
* **License:** CC BY 4.0.
* **Download Method:** Automatic direct download or manual placement in `data/raw/pepper/`.

---

## Data Usage & Compliance Statement
All datasets utilized in FarmAssist are processed solely for educational, research, and non-commercial smallholder farmer agricultural decision support under open access research licenses.
